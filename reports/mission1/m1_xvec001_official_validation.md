# M1 공식 Validation 평가 및 후보 결정 — 2026-10-10

고정된 `M1-XVEC-001`(52D 음향 특징 + 앞 20초 WavLM 512D xvector, 결합 LR)을 공식 Validation 3,640통화 전체에서 평가했다. 재학습·임계값 조정은 하지 않았다.

| 후보 | Accuracy | 정답 / 전체 | 여성 recall | 남성 recall |
|---|---:|---:|---:|---:|
| 기존 52D LR | 95.1099% | 3,462 / 3,640 | 95.8652% | 94.2296% |
| M1-XVEC-001 결합 LR | **97.4725%** | **3,548 / 3,640** | **97.9581%** | **96.9066%** |

**결정: M1-XVEC-001을 제출 후보로 채택한다.** 정확도 +2.3626%p, 정답 86건 증가로 사전에 정한 +0.5%p 기준을 충족했다. 오류는 178건에서 92건으로 감소했다. 이 결정은 평가한 고정 학습 체크포인트의 채택이며, 최종 제출 추론 패키지의 564D 입력 전환을 완료했다는 뜻은 아니다.

평가는 Colab Tesla T4에서 완료됐다(18:11:58 KST). 특징 추출 및 채점 시간 1,212.6초, 준비를 포함한 lab 작업 23.2분. 제출 형식 CSV 3,640행, 중복 파일명 없음, F/M 허용값 및 Validation 파일명 전체 일치를 확인했다. 로컬과 GPU 실행의 데이터·head·인코더 전체 SHA256이 모두 일치한다. 동일 작업의 로컬 CPU 중복 계산은 GPU 결과 검증 후 종료했고 기존 특징 캐시는 보존했다.

전체 점수·혼동행렬·해시·실행 근거는 `m1_xvec001_official_validation.json`에 기록했다. CSV와 원시 실행 결과는 Git 제외인 `outputs/model_selection/m1_xvec001_gpu/`에 보관한다. 평가 코드 커밋은 `3db888ec38b1694893b42176a45afc64a8aa4541`이다.
