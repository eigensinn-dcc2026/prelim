# M3 다음 개선 실험 — 2026-10-11

현재 상태: 구현 및 CPU 검증 진행, 전체 GPU 실험 미실행. 기존 제출 후보를 유지한다.
공식 Validation은 사용하지 않았다. 이전 유사 사례·질문/답변 모델 실패 결과는 `../context`에 보존했다.

## 실제 데이터에서 확인한 우선순위

Training 전체 29,200건을 원본 토크나이저로 분석했다. 11,642건(39.87%)이
앞 256토큰의 본문 용량 254토큰을 넘는다. 본문 길이 중앙값 228,
90분위 395, 95분위 458, 99분위 587토큰이다.

| 증상 | 기존 RoBERTa의 미탐 | 통화 전체에서 기존 정규식 미검출 | 직접 표현이 후반부에만 있음 |
|---|---:|---:|---:|
| 오심 | 408 | 396 | 3 |
| 두통 | 283 | 275 | 6 |

정규식 위치는 **어휘 기반 진단**이며 사람의 근거 주석이 아니다. 후반부 정보가
도움이 되는지 시험할 이유는 있으나, 잘림이 오심 미탐의 주원인이라고 단정할 수 없다.
손실 함수 비교와 간접 표현을 구분하는 근거 학습을 함께 검증한다.

## 고정한 비교

1. 원본 ROBERTA-003 seed42에서 인코더 1 epoch 추가 학습:
   기존 가중 BCE + microbatch soft-F1 / 가중 BCE / ASL.
   인코더 LR 1e-6, 유효 batch16, microbatch8, warmup10%.
   ASL gamma+0, gamma-4, negative clip0.05, focal weight gradient 제외.
   soft-F1의 microbatch 의존성을 구분하는 대조군이며 개선을 보장하지 않는다.
2. 같은 선택 인코더를 고정해 front256 / head+tail256 / 발화 경계를 보존한
   최대 6개 256토큰 창 / 긍정·부정·미확인 상태 head / 상태 입력 제거를 비교한다.
   모듈 차원128, dropout0.1, LR0.001, batch128, 10epoch, 가중 BCE.
   상태 모델 두 개는 동일한 보조 CE(weight0.1)를 사용하고, 제거 모델은 통화 예측에 상태 확률을 주지 않는다.
3. 대조군·기존 RoBERTa·기존 앙상블·선택한 손실 모델을 넘는 입력 방법만
   seed42/43/44로 반복한다. 이후 인코더 LR1e-6, 모듈 LR1e-4로 1epoch.
   입력 방법이 실패해도 손실 단독 모델이 기존 앙상블을 넘으면 별도로 3seed 검증한다.

발화 창은 앞부분을 그대로 유지하고 후반부까지 일정 간격으로 선택한다.
6개를 넘는 매우 긴 통화에는 미포함 구간이 생길 수 있다.
화자 번호·환자 메타데이터·오디오는 사용하지 않는다.

## 근거 상태와 품질 검토

Training 분할에서만 보수적인 규칙으로 **약한 감독 신호**를 생성한다.
실제 검토에서 “기력이 없”과 “먹을 수도 없고 토할 것 같”이 증상 부정으로
잘못 처리되는 것을 찾아 수정했다. 관련 없는 앞쪽 부정어와 담화 표현 “아니”는
부정 근거로 쓰지 않으며, 단독 “호흡/배가/피가”도 제외했다.
질문에 명확한 답변이 없으면 미확인, 상충하는 긍정·부정은 학습에서 제외한다.

수동 검토 후보는 `training_state_audit.csv`에 생성하며, 자동 규칙 결과를
수동 정답으로 표시하지 않는다. 규칙이 간접 표현을 충분히 포괄하는지는 미확인이다.
초기 로컬 진단의 weak-state 빈도는 수정 전 규칙 값이므로 최종 빈도로 쓰지 않는다.
전체 실행은 수정한 규칙으로 다시 생성한다.

## 실행

`notebooks/M3_next_experiment.ipynb`는 소스가 포함된 새 Colab 노트북이다.
기존 `outputs/m3_context_gpu/input.tar.gz` 하나만 세션 저장소에 업로드하면 된다.
기존 Colab의 과거 실험 셀들을 모두 실행하지 않는다.
누적 학습 예산은 기본6시간, 최대10시간이며 예산 초과 시 중단 상태와 결과를 보존한다.

```powershell
python scripts/train_mission3_next.py --train-label-dir TRAINING --base-ckpt BASE.pt --reference-probs-dir REFERENCE --out outputs/m3_next/run --device cuda --phase all --max-hours 6
```

Colab은 올바른 계정으로 열려 있으나 파일 업로드 도구가 Chrome의 파일 URL
접근 권한 오류를 반환했다. 아직 새 GPU 학습 지표·최종 체크포인트는 없다.
새 권한 승인은 불필요하며, 실제 Colab 창이 열린 Chrome 프로필의 설정 확인 또는
동일 파일의 수동 업로드가 필요하다.
