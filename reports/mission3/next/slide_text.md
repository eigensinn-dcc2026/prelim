# PPT용 방법 설명

**가설:** 119 통화의 증상은 직접 단어뿐 아니라 뒤쪽 맥락과 질문 이후의 답변으로 드러난다.

**진단:** 39.9%의 통화가 앞 256토큰을 넘는다. 그러나 오심 미탐408건 중396건은
통화 전체에서도 기존 정규식에 잡히지 않는다. 길이 확대만으로 해결된다고 가정하지 않는다.

**실험:** 동일한 RoBERTa에서 손실 함수 세 개를 비교한다. 이어 앞부분·앞뒤·발화 창을
같은 인코더와 학습 조건으로 대조한다. 증상별 attention이 창을 읽고
긍정·부정·미확인 근거 상태를 기존 통화 예측의 보정에 사용한다.

**창의적 설계:** “기력이 없”의 ‘없’은 쇠약의 긍정 근거다. “아니”는 담화 표현일 수도 있다.
증상 부정·다른 사건의 부정·미확인 답변을 구분하는 약한 감독 신호를 만들고
상태 입력 제거 실험으로 새 정보의 기여를 검증한다.

**판정:** 기존 앙상블과 대조군을 넘은 방법만3seed로 반복하고 통화 단위 bootstrap으로 확인한다.
조건을 통과하면 전체 Training과 대표 seed42로 학습한 후 공식 평가를 한 번 수행한다.

**현재 결과:** 데이터 진단과 구현 검증을 완료했다. 새 전체 GPU 학습은 업로드 제한으로
아직 시작하지 않았으며, 성능 향상 수치는 없다. 기존 제출 후보를 유지한다.
