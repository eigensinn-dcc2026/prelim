# Mission 3 앙상블: KcBERT + TF-IDF 확률 평균 (2026-10-10)

`p = w · p_KcBERT + (1 − w) · p_TF-IDF`, 판정 `p >= 0.5`, 후처리 없음.

- KcBERT: KCBERT-005 seed 42 (`m3_kcbert005_seed42.pt`)
- TF-IDF: P0 (`reports/mission3/m3_reeval_tfidf_lr/mission3_tfidf_logreg.joblib`, SHA256 `6dc08608…5ff7b8`)
- 두 모델 모두 같은 80:20 분할의 Training 23,408건으로 학습했습니다. 홀드아웃 5,792건의 파일 목록이 완전히 같음을 확인했습니다.

## 가중치 선택 규칙
- 가중치 `w`는 **내부 홀드아웃에서만** 0~1 범위를 0.05 간격으로 비교해 골랐습니다. 동점이면 KcBERT 비중이 큰 쪽을 택합니다.
- 공식 Validation은 고른 `w` 하나로 **한 번만** 채점했습니다.
- 가중치는 전체에 하나입니다. 증상별 가중치는 증상별 기준선 조정과 비슷해지므로 쓰지 않았습니다.
- 규정상 앙상블 가중치를 Validation으로 조정하는 것은 허용됩니다(문제명세 Validation 활용 기준).

- 홀드아웃 곡선은 w = 0.45~0.70에서 0.625~0.628로 평평합니다. 고른 값이 특정 점에 민감하지 않다는 뜻입니다.
- 공식 Val에서 9개 증상 F1이 모두 올랐습니다(+0.003~+0.015).
- 빈 예측 행은 KcBERT 299, 앙상블 306입니다.
- 앙상블이 효과가 있는 이유는 `../error_analysis/README.md` 4.2절에 있습니다.

- KCBERT-012의 가중치(0.15)는 작습니다. ROBERTA-003과 같은 손실로 학습해 실수하는 방식이 비슷한 것으로 보입니다. TF-IDF는 성격이 달라 가중치가 0.40입니다.

### 스태킹은 효과 없음
1단 모델의 logit(9증상 × 모델 수)을 입력으로 받는 선형 메타 모델을 시험했습니다. 학습은 1단과 같은 손실(가중 BCE + soft-F1)로, 홀드아웃 5-fold CV로 변형을 고른 뒤 공식 Val을 1회 채점했습니다(`m3_stacking.py`).

| | 홀드아웃 CV | 공식 Val |
|---|---|---|
| k5 + p0: 단순 평균 / 스태킹 | 0.6277 / 0.6285 | 0.6355 / 0.6338 |
| r3 + k12 + p0: 단순 평균 / 스태킹 | 0.6506 / 0.6496 | 0.6494 / 0.6493 |

증상 간 관계까지 보는 변형(full)도 단순 평균을 넘지 못했습니다. 1단 모델이 이미 같은 통화 문맥에서 함께 나오는 증상 패턴을 반영하고 있는 것으로 보입니다. **스태킹은 접고 가중 평균을 씁니다.**

### 확률 품질 (ECE·Brier)
`m3_calibration.py`, `results/calibration_p0+k5+k12+r3.json`의 공식 Val 값입니다. ECE는 증상별 15구간 평균입니다.

| 모델 | 손실 | Macro F1 | ECE | Brier | 평균 확률 − 실제 비율 | 0.5 이상 예측 비율 (실제 0.160) |
|---|---|---|---|---|---|---|
| TF-IDF | LR | 0.5689 | 0.174 | 0.123 | +0.172 | 0.187 |
| KCBERT-005 | BCE + pos_weight | 0.6246 | **0.035** | **0.080** | +0.019 | 0.129 |
| KCBERT-012 | + soft-F1 (λ=1) | 0.6351 | 0.059 | 0.087 | +0.017 | 0.149 |
| ROBERTA-002 | BCE + pos_weight | 0.6304 | **0.028** | **0.076** | +0.009 | 0.122 |
| ROBERTA-003 | + soft-F1 (λ=1) | **0.6433** | 0.052 | 0.083 | +0.020 | 0.147 |

- soft-F1은 **보정(ECE·Brier)을 약간 나쁘게 하는 대신 F1을 올렸습니다.** 두 인코더에서 같은 방향입니다. KcBERT는 ECE 0.035→0.059에 F1 +0.011, RoBERTa는 ECE 0.028→0.052에 F1 +0.013입니다(`results/calibration_r2+r3.json`).
- 평균 확률이 위로 쏠린 정도는 비슷하고(+0.019→+0.017), 0.5 이상으로 예측하는 비율이 실제 양성 비율에 가까워졌습니다(0.129→0.149). 확률을 전체적으로 올린 게 아니라 확신이 더 뚜렷해진 쪽입니다.
- 그래서 "calibration 개선"이 아니라 **"0.5 기준에서 F1이 최대가 되도록 학습한 손실 설계"**로 설명합니다. λ를 작게 섞었을 때의 비교는 M3-KCBERT-016(lab)에서 진행 중입니다.
