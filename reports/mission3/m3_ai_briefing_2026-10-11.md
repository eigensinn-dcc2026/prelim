# [브리핑] DCC 2026 예선 Mission 3 — 성능 개선 아이디어 요청

> 이 문서만 읽고 답할 수 있도록 썼습니다. 제안 전에 **4절(이미 해 본 것)**과 **3절(진단)**을 꼭 읽어 주세요.
> 기준 시각: 2026-10-11 (KST). 동결: **2026-10-12 23:59 KST** (남은 시간 약 1.5일).

## 1. 과제

- 119 신고 통화의 **전사 텍스트**(신고자·상담원 대화)로 환자 증상 9개를 다중 라벨 분류합니다.
  - 9개 증상: 고열, 구토, 두통, 복통, 어지러움, 열상, 오심, 전신쇠약, 호흡곤란
- 지표: 증상별 F1의 평균(Macro F1)
- 데이터: Training(서울) 29,200통화, 공식 Validation 3,640통화. Test는 비공개입니다.
  - 9개 증상이 하나도 없는 통화는 Training·Val 모두 0건입니다.
  - 9개 외 증상(흉통, 설사, 실신 등)도 `symptom` 필드에 있습니다. 평가에서는 빠집니다.
- 통화 길이(klue/roberta-large 토큰): p50 228, p90 393, p99 597. 256토큰에서 잘리는 통화는 39%입니다.

## 2. 규정 (어기면 실격이거나 사용 불가)

| 구분 | 내용 |
|---|---|
| 판정 | **모든 증상에 threshold 0.5 고정.** 증상별 threshold, OOF로 threshold 선택, "최소 1개 켜기"(min-1) 후처리 모두 금지. 확률 calibration은 허용 |
| 입력 | **전사 텍스트만** 사용. 메타데이터(triage, disasterMedium, 화자 정보 등) 금지 |
| 데이터 | 대회 데이터만 사용. 외부 데이터와 LLM으로 만든 합성 데이터는 위험하다고 보고 쓰지 않음 |
| Validation | 모델·하이퍼파라미터 선택, early stopping, 앙상블 가중치 조정에는 사용 가능. **학습 데이터 편입과 역전파는 금지(실격)** |
| 모델 | 공개 사전학습 모델을 받아 로컬에서 미세조정하는 것은 허용. 외부 상용 API(GPT, Claude 등) 호출 금지 |
| 전처리 | 라벨에 따라 다른 전처리 금지. 평가 데이터에만 유리한 전처리 금지 |
| 회색지대 | 증상별 pos_weight를 다르게 강화하는 것, 9개 외 증상을 보조 목표로 쓰는 것은 멘토 답변 대기 중 |

## 3. 핵심 진단: 병목은 모델이 아니라 라벨이다

증상 키워드 정규식으로 "통화에 근거가 있는 양성"과 "근거가 없는 양성"을 나눠 봤습니다.

- 양성 라벨의 **약 52%는 통화에 근거 표현이 없습니다.** 오심은 89%, 전신쇠약은 76%, 두통은 64%입니다.
- 근거가 있는 양성은 이미 **약 90%를 맞힙니다.**
- 두 모델이 **모두 놓친 양성의 92%는 근거가 없는 라벨**입니다.
- 라벨은 통화 뒤에 얻은 현장 정보로 붙은 것으로 보입니다. 메스꺼움 표현이 있는 통화 중 오심 라벨이 붙은 것은 44%뿐입니다.
- 모델은 근거가 없을 때 함께 나오는 증상으로 추측합니다(예: 어지러움·복통·구토 맥락이면 오심). 이 때문에 오심 precision이 낮습니다.
- 9개 외 증상은 통화 상황(외상, 흉부, 소화기, 신경)을 강하게 구분합니다. 예: 찰과상이 있으면 열상 확률이 5.8배, 흉통이 있으면 호흡곤란 확률이 4.3배입니다.

현재 최고 모델의 증상별 F1(공식 Val 근사): 열상 약 0.87, 복통 약 0.79, 호흡곤란·어지러움·고열 0.66~0.69, 전신쇠약 약 0.58, 구토 약 0.59, 두통 약 0.52, **오심 약 0.37**

## 4. 이미 해 본 것

평가는 모두 같은 80:20 multilabel stratified 홀드아웃(seed 42)에서 했습니다. 판정은 threshold 0.5이고 후처리는 없습니다. 값은 3-seed 평균 Macro F1입니다(별도 표시가 있는 행은 예외). 채택 기준은 기준선 대비 +0.01입니다.

### 현재 최고

| 구성 | 홀드아웃 | 공식 Val |
|---|---|---|
| **ROBERTA-003**: klue/roberta-large, 앞 256토큰, 강화 가중 BCE(pos_weight = clip(0.5·√(neg/pos), 1, 6)) + 1.0 × soft macro-F1 손실, lr 1e-5, batch 16, 3 epochs | 0.6427 | **0.6433** |
| 앙상블: ROBERTA-003 0.45 + KcBERT(soft-F1) 0.15 + TF-IDF+LR 0.40 확률 가중 평균(가중치는 홀드아웃에서 선택) | — | **0.6510** |

### 효과가 있었던 것 (누적 순서)

| 변경 | 이득 |
|---|---|
| TF-IDF+LR → KcBERT | +0.016 |
| pos_weight 완화 → 강화 | +0.010 |
| **soft macro-F1 손실 추가** | **+0.017 (KcBERT), +0.019 (RoBERTa-large)** ← 가장 큰 레버 |
| KcBERT → klue/roberta-large | +0.012 |
| TF-IDF를 앙상블에 섞기 | +0.008~0.010 (오류 방식이 달라서) |

### 효과가 없었거나 기각된 것

| 시도 | 결과 |
|---|---|
| 입력 길이: 앞128+뒤128, 슬라이딩 윈도우 3청크, 발화 턴 청크 | ±0.001 또는 하락. 256토큰 뒤에만 근거가 있는 양성은 1.5%뿐 |
| 5 epochs | −0.021 (과적합) |
| mean pooling, LLRD, R-Drop, TAPT(MLM 2 epochs) | +0.000~0.004 (노이즈 범위) |
| ASL 손실, small-loss 샘플 제외(노이즈 라벨 대응) | −0.001~−0.002 |
| 같은 모델 seed 3개 앙상블 | +0.008 |
| KcBERT+RoBERTa 0.5/0.5 평균 | +0.003 |
| 9개 외 증상 20개를 보조 헤드로 학습(가중치 0.5, BCE 또는 BCE+soft-F1) | +0.003 / −0.002 (seed 1개) |
| 보조 확률을 주 헤드 입력에 연결 | +0.0005 |
| 인코더 교체: KLUE-BERT, KcELECTRA, multilingual-e5-large, xlm-roberta-large | 모두 RoBERTa-large보다 낮음 (0.633~0.638) |
| Qwen2.5-1.5B LoRA 분류 | −0.031 |
| 선형 스태킹 | 단순 가중 평균과 같음 |

## 5. 아직 하지 않은 후보 (우리 쪽 우선순위)

1. 5-fold CV로 학습 데이터 100% 사용 + fold 앙상블, OOF로 앙상블 가중치 선택
2. OOF 앙상블 확률을 soft label로 쓰는 self-distillation (`0.5·정답 + 0.5·OOF 확률`)
3. 큰 배치(64) 또는 배치 간 TP/FP/FN 누적으로 soft-F1 기울기 안정화
4. 키워드·부정 표현·등장 위치 특징으로 LightGBM을 만들어 앙상블 멤버로 추가
5. 7~9B LLM LoRA (위험이 크고 평가 환경 GPU 제한을 아직 확인하지 못함)

## 6. 자원

- 주력은 Colab T4입니다. RoBERTa-large 1 epoch에 약 26분이 걸립니다. A100은 몇 시간 정도 쓸 수 있습니다.
- 공식 Val 채점은 Mission당 최대 6회입니다. 최종 확인에만 씁니다.
- 제출은 `inference.py` 하나로 실행되어야 하고 인터넷 없이 동작해야 합니다. 가중치는 `.pt`로 냅니다.
