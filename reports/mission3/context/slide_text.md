# PPT용 설명

## 왜 이 실험을 하는가

직접적인 증상 단어를 놓친 통화에서 다른 정보를 읽을 수 있는지 시험한다.
개선 가설은 유사 통화의 양성·음성 차이(A)와 질문 뒤의 답변 근거(B)이다.
기존 RoBERTa에 보정 모듈만 추가한 대조군을 함께 두어 추가 학습 효과와 새 정보 효과를 구분한다.

## A — 비슷해 보이는 양성과 음성을 함께 대조

Training에서 증상별 양성 8건·음성 8건을 검색한다. 두 집단의 표현과 유사도 차이를 비교하고,
전체 32개 이웃의 라벨 일치도를 읽는다. 학습한 게이트가 기존 예측을 얼마나 바꿀지 결정한다.
자기 통화·동일 통화·동일 전사본은 제외한다.

## B — 질문과 뒤의 답변을 하나의 근거로 읽기

현재 발화와 뒤의 두 발화를 묶고 증상별 attention으로 관련 묶음을 고른다.
“머리 아프세요?”와 다음 답변의 조합을 읽는 것이 가설이다. 특정 화자 번호에 의존하지 않는다.
앞 256토큰과 기존 정규화 규칙을 그대로 사용한다.

## 그림과 수치 사용

방법 설명에는 `methods.svg` 또는 `methods.png`를 사용한다.
실측 비교에는 `measured_comparison.png/svg`, 동결 학습 과정에는 `frozen_learning_curves.png`, 증상별 진단에는 `measured_diagnostics.png`를 사용한다.
축소 실행의 숫자는 본 실험 성과로 넣지 않는다. 목표 0.67과 확인된 점수를 구분한다.
동결 seed 42 Macro F1: 대조군 0.6434 / A 0.6426 / B 0.6428. 추가 학습 1 epoch: 대조군 0.6406 / A 0.6408 / B 0.6405. 기존 앙상블은 0.6539다. 모두 내부 holdout 5,792건, 임계값 0.5의 결과다. 공식 점수와 혼합하지 않는다.

두 방법 모두 실패해 반복 seed·구성 요소 제거·bootstrap·공식 평가는 실행하지 않았다. 확인하지 않은 신뢰구간이나 기여도를 발표 자료에 넣지 않는다. 실행 시간은 동결 6.17분, 추가 학습 22.71분이다. 원본 ZIP의 지표·로그·개별 예측은 검증해 보존했으나 세 실험 가중치는 GPU 세션 종료로 삭제됐다.

오심 정규식 미검출 양성 recall은 동결 RoBERTa 0.3311 / A 0.3125 / B 0.3311이었다. 간접 표현 개선을 확인하지 못했다. 256토큰 밖 답변, 검색 표현의 증상 구분 부족, 질문·부정 해석의 한계는 후속 검증 가설로 남긴다.

추가 학습 후 같은 592건의 recall은 A 0.3041 / B 0.3057로 더 낮아졌다. 오심 질문 규칙 부분집합 61건의 오탐도 기존 21건에서 A/B 각 22건으로 늘었다. 이는 단일 seed·규칙 부분집합의 관찰이며 확정 원인이나 유의성 검증 결과가 아니다.

## 채택 문장

내부 검증에서 평균 +0.003, 2개 이상 seed 개선, paired bootstrap CI 하한 >0,
Micro F1 하락 ≤0.005를 확인한다. 전체 Training 학습 후 공식 점수 ≥0.6540에서만 교체한다.
기준을 통과하지 못하면 “새 정보의 개선 효과를 확인하지 못함”으로 보고한다.
