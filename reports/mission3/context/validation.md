## 기존 내부 검증 기준

| 기준 | 통화 수 | Macro F1 | Micro F1 |
|---|---:|---:|---:|
| ROBERTA-003 | 5,792 | 0.6440965870 | 0.6568481233 |
| 기존 최고 조합: 0.45 r3 + 0.15 k12 + 0.40 p0 | 5,792 | 0.6539275341 | 0.6665417993 |

평균 +0.003 조건을 만족하려면 선택 방법의 3개 seed 평균 내부 Macro F1이 최소 0.6569275341이어야 한다. 다른 사전 채택 조건도 모두 통과해야 한다. 위 수치는 공식 점수 0.6433 / 0.6510과 별개다.

## 전체 데이터 동결 학습 결과

고정한 마지막 epoch 10을 평가했다. 검증 점수가 높은 중간 epoch를 사후 선택하지 않았다.

| 방법 | Macro F1 | Micro F1 |
|---|---:|---:|
| 통화 전체 표현 대조군 | 0.6433523047 | 0.6567994940 |
| A: 유사 사례 대조 | 0.6425616571 | 0.6559627251 |
| B: 질문·답변 근거 | 0.6427546591 | 0.6552478590 |

정규식에 잡히지 않은 오심 양성 592건의 recall은 RoBERTa 0.3311, A 0.3125, B 0.3311이다. 두통 F1도 RoBERTa 0.5270 대비 A 0.5199, B 0.5220으로 낮아졌다. 새 정보가 개선에 기여했다는 증거는 아직 없다. 학습 손실 감소와 검증 성능 향상을 구분한다.

사용자의 추가 학습 요청으로 원래 중단 조건을 변경했다. 별도 `finetune_mission3_context_pilot.py`로 control/A/B의 seed 42 epoch-10 head에서 인코더 lr 1e-6, head lr 1e-4로 각각 1 epoch를 학습했다. 기존 출력과 총 실행 예산을 공유했다. 이 단일 seed 실험은 후속 3개 seed 검증 후보를 찾는 용도이며, 자체로 채택 자격을 갖지 않는다.

실측 결과와 epoch별 로그는 `frozen_metrics.json`, `frozen_report.md`, `frozen_comparison.png`, `frozen_*_history.json`에 보관했다. 통화별 예측·개별 head 및 전체 실행 로그는 비공개 로컬 결과 ZIP에 보관했다.

## 인코더 추가 학습 결과와 판단

| 방법 | Macro F1 | Micro F1 | 동결 학습 대비 Macro 변화 |
|---|---:|---:|---:|
| 통화 전체 표현 대조군 | 0.640592 | 0.653724 | −0.002760 |
| A: 유사 사례 대조 | 0.640794 | 0.654096 | −0.001768 |
| B: 질문·답변 근거 | 0.640496 | 0.653670 | −0.002259 |

이 표는 검증한 원본 결과 ZIP의 `metrics.json`을 소수 6자리로 표시한 것이다. 전체 정밀도 값은 대조군 0.6405919725316895, A 0.6407935785780812, B 0.6404957630120178이다. 기존 앙상블과의 Macro 차이는 A −0.013134, B −0.013432다. A가 추가 학습 대조군보다 0.000202 높지만, 원본 RoBERTa와 앙상블 기준을 모두 넘지 못했다. 상태는 `fine_pilots_failed`, 선택 방법은 없다.

따라서 3개 seed 반복, 구성 요소 제거, paired bootstrap, 전체 Training 최종 학습, 공식 평가는 실행하지 않았다. 신뢰구간이나 새 정보의 인과적 기여를 주장하지 않는다. 구현된 추론·패키지 템플릿과 실험용 체크포인트 export는 제출 후보 채택과 별개다.

추가 학습 후 정규식 미검출 오심 양성 592건의 recall도 RoBERTa 0.3311 대비 대조군 0.3074, A 0.3041, B 0.3057로 낮아졌다. 오심 질문 규칙 부분집합 61건의 오탐은 RoBERTa 21건, 대조군 20건, A/B 각 22건이었다. 기대한 간접 표현 recall 또는 질문 오탐 감소가 이 부분집합에서 확인되지 않았다. 부정 답변 규칙 부분집합은 4건뿐이므로 일반화하지 않는다. 전체 증상별 precision·recall과 질문·부정 부분집합은 `fine_metrics.json`에서 확인할 수 있다.

동결 학습에서 손실이 줄어도 검증 성능이 개선되지 않았고, 1 epoch 추가 학습에서는 세 모델 모두 더 낮아졌다. 256토큰 밖의 답변 누락, CLS 검색 공간의 증상 구분 부족, 단순 발화 평균 표현의 질문·부정 해석 부족, 추가 학습 과적합은 가능한 원인 가설이다. 구성 요소 제거 및 의미 주석 검증을 하지 않았으므로 확정 원인으로 제시하지 않는다.

## 파일 보존 및 복구 한계

동결 결과 ZIP은 로컬에 보존되어 전체 지표·history·개별 예측·head를 다시 읽을 수 있다. 추가 학습 후 세 self-contained 실험 체크포인트의 export 성공과 SHA256은 원본 노트북과 `fine_checkpoint_manifest.json`에 남아 있다. 결과 ZIP에는 가중치가 포함되지 않았다. 중단 후 재연결한 세션은 새 VM이었고, `/content`에는 `.config`와 `sample_data`만 있었다. 사용자가 이전 세션을 종료한 경위와 가중치 삭제를 확인했다. **export 완료 로그는 모델 파일 복구의 증거가 아니다.**

실행 출력 포함 원본 노트북을 `outputs/m3_context_gpu/Colab_M3_executed_20261011.ipynb`에 보존했다. 최초에는 이 노트북의 stdout으로 집계 값을 복구했으나, 이후 사용자가 ZIP 경로를 알려줘 원본 결과로 교체했다. 743,970바이트 ZIP의 CRC 무결성, 모든 추출 경로, 동결 실험과의 source hash 일치, 세 방법의 5,792×9 예측·정답 배열을 확인했다. ZIP SHA256은 `bf17118ae6ae7e642b145888477af7a3410ecae67f1656b777960372a887223e`다.

요청대로 ZIP을 다운로드 폴더에서 `outputs/m3_context_gpu/m3_context_fine_results_20261011.zip`으로 옮겼고, 추출본은 `outputs/m3_context_gpu/downloaded_fine/run_fine_pilot`에 보관했다. 공유 가능한 전체 집계 지표·리포트·로그·체크포인트 목록은 `fine_metrics.json`, `fine_report.md`, `fine_execution.log`, `fine_export.log`, `fine_checkpoint_manifest.json`으로 복사했다. 통화별 예측 NPZ는 비공개 outputs 폴더에만 보관한다.

기존 GPU 세션의 모델 파일은 복구할 수 없다. 재생성하려면 같은 설정으로 다시 학습해야 한다. 이번 방법들은 채택 기준을 통과하지 못했으므로 모델 복원만을 위한 재학습은 진행하지 않았다. 새 빈 GPU 세션은 비용 절감을 위해 종료했다. 사용자 전달 종료 기록의 남은 단위는 114.62, 활성 세션은 0개였으며 이 수치를 현재 잔액으로 다시 측정했다고 주장하지 않는다.

사용자가 지정한 [Colab 노트북](https://colab.research.google.com/drive/1nB8l_Yl9CWZzKKy8rwhMtWra-PqJdvk5?authuser=1)에 A100-SXM4-40GB, Python 3.13.15, torch 2.11.0+cu130을 확인했다. transformers 4.57.6 설치 및 합성 인코더의 유한 출력·gradient를 확인했다. 노트북에는 입력 해시 검증, 축소 점검, 고정 설정의 전체 실행, 로그 저장 셀을 준비했다.

브라우저 도구의 업로드 오류 이후 사용자가 준비된 `input.tar.gz`와 `source.zip`을 전달해 실행했다. 두 파일의 데이터 수·체크포인트 SHA256 확인을 통과했다. 이 묶음에는 비공개 Training 텍스트와 라벨이 있으므로 공개 저장소에 게시하지 않는다. 동결 실험 결과 ZIP 27,128,877바이트를 로컬에 내려받아 보존했다. 추가 학습 코드는 사용자가 지정한 같은 비공개 Colab 노트북에 저장했다.

동결·추가 학습의 실행 시간 합계는 약 28.88분이다. 앞서 확인한 5.3 CU/시간 사용률을 적용하면 실행 자체는 약 2.55 CU, 추가 학습은 약 2.01 CU다. 이는 전송·환경 준비·export·대기·연결 시간을 제외한 추정이며 실제 계정 사용량 차이를 확인한 값은 아니다. 내부 채택 기준을 통과한 후보가 없어 최종 Training 학습과 공식 평가를 수행하지 않았다.
