## 기존 내부 검증 기준

기존 holdout NPZ를 파일 이름으로 정렬해 재계산했다. 임계값은 0.5다.

| 기준 | 통화 수 | Macro F1 | Micro F1 |
|---|---:|---:|---:|
| ROBERTA-003 | 5,792 | 0.6440965870 | 0.6568481233 |
| 기존 최고 조합: 0.45 r3 + 0.15 k12 + 0.40 p0 | 5,792 | 0.6539275341 | 0.6665417993 |

평균 +0.003 조건을 만족하려면 선택 방법의 3개 seed 평균 내부 Macro F1이 최소 0.6569275341이어야 한다. 다른 사전 채택 조건도 모두 통과해야 한다. 위 수치는 공식 점수 0.6433 / 0.6510과 별개다.

## GPU 실행 환경과 재개

사용자가 지정한 [Colab 노트북](https://colab.research.google.com/drive/1nB8l_Yl9CWZzKKy8rwhMtWra-PqJdvk5?authuser=1)에 A100-SXM4-40GB, Python 3.13.15, torch 2.11.0+cu130을 확인했다. transformers 4.57.6 설치 및 합성 인코더의 유한 출력·gradient를 확인했다. 노트북에는 입력 해시 검증, 축소 점검, 고정 설정의 전체 실행, 로그 저장 셀을 준비했다.

실측 Colab 사용률은 약 5.3 CU/시간이다. 계획한 5~10시간은 약 27~53 CU이며, 전송·준비·대기도 과금되므로 60~70 CU를 확보하는 편이 좋다. 사용률과 GPU 배정은 Colab에서 달라질 수 있다.

Chrome 확장 프로그램의 파일 URL 권한 변경을 사용자가 승인하고 완료했다고 알려주었지만, 도구는 페이지 새로고침 후에도 업로드 권한 오류를 반환했다. 내부 설정 페이지는 브라우저 도구의 URL 정책상 접근할 수 없다. 전체 실험을 재개하려면 준비된 `outputs/m3_context_gpu/input.tar.gz`와 `source.zip`을 Colab 세션 저장소로 전달해야 한다. 이 묶음에는 비공개 Training 텍스트와 라벨이 있으므로 공개 저장소에 게시하지 않는다.

입력 파일을 받지 못한 점검용 A100 세션은 종료했다. 종료 후 활성 세션 0개, 사용률 약 0 CU/시간, 잔여 122.37 CU를 확인했다. Colab 노트북의 코드와 점검 출력은 저장되어 있다. 재개할 때 A100에 연결하고 준비된 두 파일을 전달한 뒤 의존성·입력 확인·축소 실행·전체 실행 순서로 진행한다.

실제 학습을 마치면 이 기록과 별도로 실행 폴더의 `metrics.json`, `report.md`, `comparison.png`, 실행 로그, seed별 결과 및 bootstrap 구간을 보관한다. 내부 채택 기준을 통과한 후보에만 최종 Training 학습과 공식 평가를 수행한다.
