## 남은 항목

- M3는 Training 80%로 학습한 기존 후보다. 전체 Training 최종 학습이 완료되면 새 `.pt`와 해당 학습의 실행 출력이 보존된 노트북으로 교체하고 다시 검사한다. 새 앙상블을 채택하는 경우 `m3/final-train-kit`의 앙상블 대응 모델 코드·의존성도 함께 반영해야 한다.
- M2-RERUN-001 최종 3-seed 가중치와 대응하는 실행 노트북이 없다. 현재 참고 노트북과 임의 가중치 코드 검사 기록으로 대체하지 않는다.
- M1·M3 현재 노트북에는 실제 학습 기록을 markdown으로 보존했지만 코드 셀 실행 출력은 없다. M1은 최종 학습 기록 제출 가능 여부를 별도로 확인하고, M3는 예정된 최종 실행 노트북으로 보완한다. 실행 출력 자체만 있어도 해당 가중치와 대응한다고 자동 판정하지 않는다.
- 새 가상환경에서 requirements를 처음 설치하는 검사는 수행하지 않았다. M1·M2 실행 검사는 기존 manifest의 기록이며 이번에는 다시 실행하지 않았다.

## 재실행

```powershell
python scripts/preflight_submission.py
```

현재 확보본 전용 도구다. 결과는 `preflight.json`에 저장된다. 준비 완료는 종료 코드 0, 자료·검증 보완 필요는 2, 검사 실패는 1이다. 제출 파일을 교체한 경우에는 가중치 출처·노트북 대응 관계·검증 참조 CSV를 확인하고 도구의 현재 M3 파일명·sidecar·참조 경로를 새 자료에 맞게 갱신한다. 검증한 파일로 압축본과 manifest를 갱신한 뒤 해시 검사를 다시 수행해야 한다. 검사 실패를 숨기기 위해 기존 manifest의 해시만 바꾸지 않는다.

원본 통화 텍스트와 통화별 예측은 보고서에 포함하지 않았다. 새 가중치 도착을 기다리는 자동화는 생성하지 않았다.
