# M2-PAD-001 / M2-VAL-005 — 발화 자기 자신만 고정 길이로 채우기

> **2026-10-02 주의**: 이 보고서가 다루는 L2 모델 `m2_cnn_large.pt`(그리고 L1 `m2_baseline_lgbm_tuned_postfix2.pkl`)는

> 이 문서의 숫자는 **2026-09-28에 로컬 컴퓨터에서 직접 실행한 결과**입니다. 실행에 쓴 임시 스크립트
> (분할 재현·길이 비교, 청크 실행기)와 예측 CSV는 커밋하지 않았습니다. 코드 수정

## 왜 했나

M2-VAL-004에서 제출용 스크립트(발화 하나씩, 채우기 없음)가 89.73%로, 예전 90.88%(배치 평가)보다
약 1.15%p 낮게 나왔다. 학습 때는 배치마다 가장 긴 발화에 맞춰 무음(-80 dB)을 채워서 모델이 무음이
붙은 입력에 익숙한데, 제출용 스크립트는 채우지 않아서 생긴 불일치로 의심됐다. 그렇다면 **다른 발화를
전혀 안 쓰고 그 발화 자기 스펙트로그램만 정해진 길이까지 채워도** 격차가 사라져야 한다.

## 1단계 (M2-PAD-001): 재학습 없이 채우는 길이 비교

- **모델**: `m2_cnn_large.pt` 그대로(재학습 없음).
- **선택용 데이터는 공식 Validation이 아니라 학습 데이터 내부 검증 통화**: 로컬 학습 JSON 29,200개의
  `_id`로 `GroupShuffleSplit(test_size 0.2, seed 42)`를 다시 만들어(학습 통화 23,360 / 검증 통화 5,840)
  검증 통화 250개(7,867발화)를 무작위로 뽑음. 이 분할은 그 모델의 실제 학습 때 쓴 인덱스(Colab)를 직접
  본 게 아니라 다시 만든 것이라, 확인용으로 학습 통화 100개(2,865발화)도 같은 방식으로 평가함.
  **학습 통화 92.60% vs 검증 통화 89.58%**로 학습 쪽이 3%p 높아서, 분할이 맞게 재현됐다는 정황 증거로
  봄(분할이 틀렸다면 두 값이 비슷해야 함. 다만 증명은 아님).
- **방식**: 스펙트로그램 프레임 수가 L보다 짧으면 L까지 뒤를 -80 dB로 채움, 이미 L 이상이면 그대로.

| 채우는 길이 L (프레임, 1프레임 = 20 ms) | 검증 통화 정확도 |
|---|---|
| 채우지 않음 | 89.58% |
| 100 (2초) | 90.63% |
| 200 (4초) | 90.72% |
| **300 (6초)** | **90.84%** |
| 500 (10초) | 90.80% |
| 800 (16초) | 90.59% |

발화 길이별(채우지 않음 → L=300): 0.5초 미만 85.8% → 90.0%, 0.5~1초 85.6% → 87.9%, 1~2초 87.0% →
88.0%, 2~4초 94.1% → 94.2%, 4초 이상 98.4% → 98.4%. 예측의 약 2.8~4.4%가 채우기 때문에 바뀜.
발화 길이는 중앙값이 73프레임(약 1.5초), 75%가 131프레임 이하, 95%가 274프레임 이하.

L=200~500은 사실상 평평해서 길이를 정밀하게 고를 필요는 없다고 보고, 가운데인 **300**을 골랐다.

## 2단계 (M2-VAL-005): 공식 Validation 1회 확인

- L=300을 넣은 `mission2_inference.py`를 공식 Validation 전체(통화 3,640건/발화 111,947개)에 실행.
  M2-VAL-004와 같은 방식(로컬 CPU, 통화 120개씩 31묶음, 6개 프로세스, 실제 명령행 호출). 재학습·재튜닝
  없음. 길이는 위 내부 검증에서 정했고 공식 Validation은 **확인용으로 한 번** 썼다.

| | 정확도 | 대원(0) 정답률 | 신고자(1) 정답률 |
|---|---|---|---|
| M2-VAL-003 일괄 처리 평가, 로컬 CPU | 90.89% | 86.75% | 94.72% |
| M2-VAL-004 제출용 스크립트, 채우기 없음 | 89.73% | 87.26% | 92.02% |
| **M2-VAL-005 제출용 스크립트, 300프레임까지 채움** | **90.89%** (101,750 / 111,947) | 87.10% | 94.40% |

- 예측 실패로 대체된 발화 0건. 채우지 않은 결과와 비교해 예측의 3.3%가 바뀜.
- 발화 길이별(채우지 않음 → 채움): 0.5초 미만 86.2% → 90.3%, 0.5~1초 85.0% → 86.8%, 1~2초 88.2% →
  89.1%, 2~4초 94.2% → 94.5%, 4초 이상 97.9% → 98.0%.
- **추론 시간은 약 2배**: 같은 조건(31묶음 병렬)에서 260초 → 502초. 모든 발화가 최소 300프레임으로
  처리되기 때문. 채점 환경이 느리면 부담이 될 수 있어서, 계산량 보고(대회 권장 사항)에 이 값을 써야 함.

## 의미

1. **격차는 "이웃 발화 정보" 때문이 아니라 "학습과 추론의 입력 모양이 달라서"였던 것으로 보인다.**
   발화 자기 자신만 채웠는데 -1.15%p 격차가 사라졌다(89.73% → 90.89%). 다른 발화를 하나도 쓰지 않으므로
   격리 발화 규정에 걸리지 않는 방식으로 예전 배치 평가 수치를 재현했다.
2. **보고할 수치**: 이 방식의 90.89%는 발화를 하나씩 따로 처리해 얻은 값이라 격리 발화 기준으로 말할 수
   있다. M2-VAL-003의 측정 방식(배치 최장 길이에 맞춰 채우기) 자체는 여전히 이웃 발화의 영향이 섞이는
   방식이라, 같은 수치를 보고하더라도 이 방식으로 재현한 값을 근거로 삼는 게 안전하다.
3. 이득은 짧은 발화(0.5초 미만 +4.0%p, 0.5~1초 +1.9%p)에 집중된다. 짧은 발화를 돕겠다는 시도들
   (M2-CNN-004~007)이 모두 실패한 구간에서 처음으로 확인된 이득이다.
