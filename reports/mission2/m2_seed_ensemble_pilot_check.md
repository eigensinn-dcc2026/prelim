# M2-ENS-002 — 같은 CNN을 seed만 바꿔 여러 개 합치기: 예비 확인 (통과) / M2-ENS-003 진행 상황

> **2026-10-02 주의**: 이 보고서가 다루는 L2 모델 `m2_cnn_large.pt`(그리고 L1 `m2_baseline_lgbm_tuned_postfix2.pkl`)는
> Training 6통화의 라벨을 교정한 데이터로 학습한 것이라 **제출할 수 없다**(운영진 답변, `docs/decisions.md` 2026-10-02).
> 숫자는 과거 기록으로 그대로 두고, 제공된 라벨로 다시 학습한 모델로 대체한다(M2-RETRAIN-001).

> 이 문서는 **다른 Claude 세션이 2026-09-29에 실행한 결과를 이 세션의 기록(메모리)에서 옮겨 적은
> 것**입니다. 실행에 쓴 예비 확인 스크립트(`colab_scripts/M2_Colab_L2_seed앙상블_예비확인_스크립트.py`,
> DCC 루트 하위, git 미포함)는 저장소 밖에 있고, 조합 4개(쌍 3개 + 세 개 전부)의 개별 수치는 이
> 세션의 기록에 범위로만 남아 있어 표로 재구성하지 못합니다 — 세 개 전부 합친 조합의 값만 정확히
> 남아 있습니다. 이 문서를 쓴 세션은 실행을 직접 보지 않았고 재현도 하지 않았습니다.

## 왜 했나

M2-ENS-001(L1+L2 점수 합치기)이 기각된 뒤, 같은 CNN을 seed만 바꿔 여러 개 학습해서 합치는 방법은
아직 시험하지 않은 채로 남아 있었다. 전체 데이터(29,200통화)로 CNN을 2개 더 학습하는 건 GPU로
몇 시간이 걸리는 일이라, 그 전에 "지금 가진 파일럿 체크포인트만으로도 합치면 나아지는 조짐이
있는가"를 먼저 싸게 확인했다.

## M2-ENS-002: 예비 확인 (재학습 없음)

- **재료**: M2-CNN-007에서 이미 학습해 둔 파일럿 체크포인트 3개(통화 3,000건, `n_mels=40`,
  `torch-seed` 1/2/3) — 각각 [`m2_cnn_nmels_seed_recheck.md`](m2_cnn_nmels_seed_recheck.md)에 이미
  기록된 held-out 18,134발화 기준 단독 정확도: **ts1 88.88% / ts2 88.63% / ts3 88.88%**. 새로
  학습한 모델은 없다.
- **방법**: 세 모델의 softmax 확률을 평균(soft-vote)해서 쌍 3개(ts1+ts2, ts1+ts3, ts2+ts3)와 세 개
  전부(ts1+ts2+ts3) 총 4개 조합을 만들고, 같은 held-out 세트(M2-CNN-006/007/AUG-001과 같은 split
  seed=42)에서 각 조합의 정확도를 그 조합에 속한 모델 중 제일 좋은 단독 정확도와 비교했다. 공식
  Validation은 쓰지 않았다.
- **판정 기준(실행 전 고정, 최종 채택 기준(+0.5%p)보다 낮은 "진행 여부만 보는" 기준)**: 4개 조합 중
  3개 이상이 양수이고, 세 개 전부 합친 조합이 +0.3%p 이상이면 "신호 있음 → 전체 데이터로 2개 더
  학습해서 진짜 앙상블을 시험할 가치가 있다"로 판정, 못 넘으면 "여기서 멈추는 게 낫다"로 판정하도록
  스크립트에 미리 정해 두었다.
- **결과**: 4개 조합 전부 양수(+0.31%p ~ +0.48%p 사이, 세 개 전부 합친 조합은 **+0.48%p**) — 기준
  통과. 이번 세션 동안 시도한 것 중 부호가 흔들리지 않고 전부 같은 방향으로 나온 유일한 결과였다고
  기록되어 있다.
- **주의**: 파일럿 체크포인트(통화 3,000건)로 한 예비 확인이라 판정 기준 자체가 최종 채택
  기준(+0.5%p)보다 낮다. "합칠 가치가 있어 보인다"이지 "채택 결정"이 아니다.

## M2-ENS-003: 전체 데이터로 CNN 2개 더 학습 (진행 중, 현재 일시 중단)

- M2-ENS-002가 통과해서, 실제 제출 후보인 `m2_cnn_large.pt`(전체 29,200통화, `--torch-seed` 없이 학습,
  best_epoch 21/30, 내부 검증 91.22% — 배치 평가 기준)와 같은 조건으로 `--torch-seed 2`, `--torch-seed 3`
  두 모델을 전체 데이터로 추가 학습하기로 했다. 기존에 만들어 둔 스펙트로그램 캐시를 재사용해서 학습만
  하면 되도록 준비되어 있다(`colab_scripts/M2_Colab_L2_seed앙상블_전체학습_스크립트.py`, `--resume` 지원).
- **평가 계획(아직 실행 전)**: 새 체크포인트 2개가 준비되면, M2-ENS-001과 같은 학습 데이터 내부 검증
  통화 1,200개에서 통과 기준 +0.5%p(파일럿보다 엄격한 최종 채택 기준)로 먼저 확인하고, 통과할 때만
  공식 Validation에서 1회 확인하기로 계획되어 있다. 실제 제출 스크립트(`mission2_inference.py`)에
  앙상블을 넣는 건 이 계획이 통과할 때만 진행할 별도 후속 작업이다.
- **현재 상태(2026-09-29)**: **Colab Pro GPU 할당량이 소진되어 일시 중단**됐다. 모델 1개만 먼저
  학습하거나 다른 무료 GPU(Kaggle 등)로 옮기는 대안도 있었지만, 할당량이 다시 찰 때까지 기다리기로
  했다. 재개할 때는 위 스크립트를 그대로 다시 돌리면 된다(수정 불필요). 아직 학습된 모델도, 평가
  결과도 없다.

## 이 시점까지의 패턴

이번 세션에서 시도한 단일 모델 개선 아이디어(발화 길이 입력, hop 축소, n_mels 확대, L1+L2 합치기,
SpecAugment, SWA, ResNet, 마스크 풀링)는 전부 각자 미리 정한 기준을 통과하지 못했다. seed 앙상블만
파일럿 규모에서 일관된 양의 신호를 보였다 — 그래서 이 방향을 계속하기로 한 것이지, 다른 방향들과
달리 특별히 유리한 이론적 근거가 있어서는 아니다.
