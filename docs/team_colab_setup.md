# 팀원 Colab 실행 준비 (1회, 경로 수정 불필요)

노트북·스크립트는 `src/dcc_data/colab_env.py`가 데이터·출력 경로를 자동으로 찾습니다.
내 드라이브에 아래 바로가기를 추가하면 됩니다. 팀 `dcc_runs`에 쓸 수 없으면 출력 경로만 `DCC_RUN_ROOT`로 바꿉니다.

## 1. 내 드라이브 최상단에 바로가기 추가

공유받은 폴더를 Drive 웹에서 우클릭 → **정리 → 바로가기 추가 → 내 드라이브**. **이름은 바꾸지 마세요.** 이 이름으로 자동 탐색합니다.

| 바로가기 이름 | 용도 | 확인 |
|---|---|---|
| `대학부 데이터` | 공식 배포 데이터 | 열면 `Training/`, `Validation/`이 바로 보여야 함. 추가는 아래 3. 데이터 |
| `dcc_runs` | 체크포인트·로그 저장 | 팀 폴더에 결과를 쓸 때만 편집자. 없으면 아래 권한처럼 `DCC_RUN_ROOT`로 자기 폴더 지정 |

- `대학부 데이터 (1)`처럼 이름이 바뀌었으면 `대학부 데이터`로 되돌립니다.

## 권한

팀 Drive `MyDrive/dcc_runs`에 결과를 쓸 때만 편집자 권한이 필요합니다. 학습 자체에는 이메일 공유가 필요 없습니다.
혼자 돌릴 때는 `DCC_RUN_ROOT`를 자기 Drive 폴더로 지정합니다. 예: `/content/drive/MyDrive/dcc_runs_me`.
끝나면 결과 폴더를 팀에 공유하거나, 실행 담당에게 링크를 줍니다.

## 2. 실행

1. Colab 런타임을 GPU로 변경합니다(L1은 CPU 가능).
2. 첫 설정 셀 실행 → Drive 마운트 허용.
3. 출력에 데이터 경로가 찍히면 성공입니다. 실패하면 시도한 경로 목록과 안내가 오류로 나옵니다.

## 코드 전달 (`team_handoff/`)

리포가 private이라 GitHub 접근이 없는 팀원을 위해, 실행 담당이 Drive에 `team_handoff/`를 둡니다.
이 폴더에는 코드만 넣습니다. 실행 스크립트, 학습 스크립트, 코드 zip, `SHA256SUMS.txt`, 기준 커밋을 적은 `README.txt`입니다. 데이터와 체크포인트는 넣지 않습니다.
파일마다 sha256은 GitHub main(또는 해당 PR 브랜치)의 파일과 같아야 합니다.
팀원에게는 뷰어로 공유합니다. 이메일 공유를 권장합니다. 링크 공유는 사령탑 승인 후에만 합니다. 우리 폴더는 링크 공개하지 않습니다(아래 주의).

팀원은 폴더를 자기 MyDrive로 복사하거나 바로가기를 추가한 뒤, Colab에서 `sha256sum -c SHA256SUMS.txt`로 확인하고 실행합니다.

P1 v4 실행 스크립트는 예정입니다(PR `exec/m3-p1-v4`). 코드 zip은 다음 순서로 찾습니다.

1. `$M3P1_ZIP`
2. 스크립트와 같은 폴더
3. `$RUN_ROOT/code/`
4. MyDrive 루트

제출 후보 실행은 노트북 셀 안에서 실시간 출력으로 돌리고, 노트북을 출력과 함께 Drive 실행 폴더에 저장합니다.

## 3. 데이터

공식 데이터 폴더(`2026 DCC 대학부 데이터` > `대학부 데이터`)는 주최 측 계정 소유다(2026-10-06 Drive 메타데이터로 확인). 주최 측이 배포한 공유 링크로 열어 자기 MyDrive에 바로가기를 추가한다.

바로가기 이름은 `대학부 데이터`로 둔다. Colab에서는 `/content/drive/MyDrive/대학부 데이터`로 보인다. Drive가 같은 폴더를 `/content/drive/.shortcut-targets-by-id/*/대학부 데이터`에 두는 경우도 있고, `colab_env.py`는 둘 다 찾는다.

데이터를 다시 공유하거나 우리 팀 계정/외부로 복사해 공유하는 것은 금지. Colab VM의 /content로 복사해 푸는 것만 허용. Drive FUSE에서 바로 읽지 않는다.

주최 측 공유 링크가 안 열리면 총괄에게 알린다.

## 주의

- 데이터는 팀원 외에 공유하지 않습니다(링크 공개 금지).
- 같은 `dcc_runs/m2_l2_rerun_<커밋>`을 두 사람이 동시에 학습하면 체크포인트가 충돌할 수 있습니다. 실행 전에 누가 어떤 노트북을 돌리는지 공유하세요.

## 탐색 순서

| 대상 | 우선순위 |
|---|---|
| 데이터 | 인자 → `DCC_DATA_ROOT` → `M1_DATA_ROOT` → `data/raw_original` → `MyDrive/대학부 데이터` → `.shortcut-targets-by-id/*/대학부 데이터` → 공유 드라이브(`Shareddrives`, `Shared drives`) |
| 출력 | 인자 → `DCC_RUN_ROOT` → `MyDrive/dcc_runs` (Colab) → `outputs/` (로컬) |

- `DCC_DATA_ROOT` 또는 `M1_DATA_ROOT`를 지정했는데 `Training/`·`Validation/`이 없으면 다른 경로로 넘어가지 않고 오류를 냅니다.
- 로컬은 `DCC_DATA_ROOT`만 지정하면 됩니다.
