# 결과 정리 PPT (ppt/)

예선 제출물 중 하나인 **결과 정리 PPT**를 관리하는 폴더입니다. 심사위원이 발표 없이
이 파일만 읽고 본선 진출 여부를 판단하므로, 모든 슬라이드는 설명 없이도 결론이
보이게 구성합니다.

## 절대 지키세요: `.pptx` 파일을 PowerPoint로 직접 열어서 고치지 마세요

`.pptx`는 그림 파일과 같은 바이너리 파일이라 Git이 "누가 어디를 고쳤는지" 비교하지
못합니다. 두 사람이 동시에 PowerPoint에서 수정하고 각자 커밋하면, 나중에 머지할 때
**한쪽 작업이 그냥 사라집니다.** 그래서 이 폴더는 일반 코드 PR과 똑같은 방식으로
작업합니다.

```
ppt/
├── DCC2026_예선_결과정리.pptx   # 산출물 — build_deck.js로만 재생성, 직접 편집 금지
├── build_deck.js                # ← 여기를 수정하세요 (일반 텍스트라 git diff/merge 가능)
├── figures/                     # 공식 템플릿 이미지 + EDA 그래프 (reports/eda/figures 원본)
└── design_guide.md              # 색상·폰트·레이아웃 디자인 규칙 참고 문서
```

## 작업 순서 (WORKFLOW.md와 동일)

1. `git switch main && git pull --ff-only origin main`
2. 자기 작업 브랜치 생성 — 이름 규칙은 기존과 동일 `이름/ppt-missionN`
   - 예: `jangsoo/ppt-mission1`, `gwanghee/ppt-mission2`, `jieun/ppt-mission3`
3. `ppt/build_deck.js`에서 **자기 미션 블록만** 수정
   - Mission 1: `missionA(9, 1, ...)` / `missionB(10, 1, ...)` 호출부
   - Mission 2: `missionA(11, 2, ...)` / `missionB(12, 2, ...)` / 12p(기각/보류 표)
   - Mission 3: `missionA(14, 3, ...)` / `missionB(15, 3, ...)` / 15p(확장 계획)
   - 회색 `〔 〕`로 감싼 텍스트는 아직 채울 자리표시자입니다. 실제 값으로 바꾸면서 `〔 〕`를 지우세요.
   - 분홍색 "잠정 · N/N 기준" 태그(`tag(s, ...)` 호출)가 있는 슬라이드는 수치가 확정되면
     태그 자체를 지우거나 날짜를 갱신하세요.
4. 로컬에서 빌드해 확인:
   ```bash
   npm install pptxgenjs   # 최초 1회
   node build_deck.js DCC2026_예선_결과정리.pptx
   ```
5. 결과 `.pptx`도 같이 커밋 — PR엔 `build_deck.js` diff와 재생성된 `.pptx`가 함께 올라갑니다.
6. PR 올리고 팀원 리뷰 받은 뒤 병합 (코드 PR과 동일한 흐름)

## 같은 미션을 여러 명이 동시에 고칠 때

`build_deck.js`는 일반 텍스트라 Git이 충돌 지점을 알려줍니다. 다만 같은 함수
호출부(예: 같은 `missionB(...)` 블록)를 동시에 건드리면 충돌 해결이 필요할 수 있으니,
같은 미션 담당자끼리는 작업 전에 "지금 내가 11~13p 고친다" 정도만 가볍게 공유하세요.

| 장 | 내용 |
|---|---|
| 1 | 표지 (D+AICC 공식 템플릿 원본, 수정 금지) |
| 2 | 프로젝트 타이틀·팀명 |
| 3 | 목차 |
| 4–5 | 01 준비 과정 |
| 6–8 | 02 데이터 분석 (EDA는 `reports/eda/figures/` 실제 그래프 사용) |
| 9–10 | Mission 1 |
| 11–13 | Mission 2 (+ 12p 다른 접근·기각 이유) |
| 14–16 | Mission 3 (+ 15p 확장 계획) |
| 17–18 | 04 종합 및 시사점 |
| 19 | 마무리 (공식 템플릿 원본, 수정 금지) |

표지·마무리(1, 19p)는 공식 템플릿 이미지를 그대로 쓰고 있어 **내용을 바꾸지 마세요.**
나머지 장은 상단에 공식 헤더 띠(`figures/tpl_header.png`)가 공통으로 붙어 있습니다.
